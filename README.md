# Jennifer Addo — Cybersecurity Project Portfolio
A project-focused cybersecurity portfolio documenting practical work across incident response, phishing analysis, digital forensics and network traffic analysis.
The portfolio is designed to go beyond a traditional CV by showing the investigation process behind each project, the tools used, the evidence reviewed and the reasoning behind each conclusion.

Featured Projects
Independent Incident Response Lab
Built an isolated multi-VM environment using Kali Linux and victim machines to work through a structured SOC-style incident-response exercise.
The project covers:
- Identification and investigation
- Containment considerations
- Remediation recommendations
- Incident reporting
- Lessons learned

Phishing Email Investigation
Created and analysed a simulated phishing email in a safe environment.
The investigation documents:
- Suspicious sender information
- Urgency and social-engineering techniques
- Generic greeting patterns
- Account-verification links
- Evidence supporting the final conclusion
  
Digital Forensics Investigation
Conducted a forensic investigation using Autopsy and an E01 training disk image.
The project includes:
- Review of more than 1,000 deleted-file entries
- Microsoft Office artefact analysis
- Metadata and timestamp review
- Evidence screenshots
- Evidence-based reporting
  
A key focus of this investigation was distinguishing between what the evidence suggested and what it could actually prove.
Network Traffic Analysis
Used Wireshark to capture and examine live network traffic in a controlled environment.
The project focuses on:
- Packet-level analysis
- Navigating packet captures
- Understanding communication between devices
- Connecting networking theory with practical observations

Investigation Approach
My projects follow a simple principle:
Evidence first. Assumptions last.
I focus on documenting what was observed, preserving the reasoning behind findings and being clear about the limits of the available evidence.
This portfolio will continue to develop as I complete new security labs, investigations and technical projects.
